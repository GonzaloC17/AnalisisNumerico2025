Método de Gauss-Jordan

¿Qué hace este método?

Transforma la matriz aumentada [A|b] en una matriz identidad [I|x], donde x es la solución del sistema Ax = b.

Pasos del algoritmo:

  1. Para cada fila i, obtener el coeficiente diagonal principal
  2. Dividir toda la fila por ese coeficiente
  3. Hacer ceros los demás elementos de la columna
  4. Repetir hasta obtener matriz identidad

Ventajas:

  • Solución directa sin sustitución hacia atrás
  • Muestra claramente los pasos intermedios
  • Fácil de implementar y entender

Nota: El sistema debe ser cuadrado (n×n) y no singular para tener solución única.
