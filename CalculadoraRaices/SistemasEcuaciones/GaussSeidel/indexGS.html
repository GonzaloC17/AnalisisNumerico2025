Método de Gauss-Seidel

¿Qué hace este método?

Método iterativo que resuelve sistemas de ecuaciones lineales Ax = b mediante aproximaciones sucesivas, usando los valores más recientes en cada iteración.

Fórmula de iteración:

xi(k+1) = (bi - Σj<i aijxj(k+1) - Σj>i aijxj(k)) / aii

Criterio de convergencia:

El método converge si la matriz es diagonalmente dominante o si el radio espectral de la matriz de iteración es menor que 1.

Criterio de parada:

Se detiene cuando ||x(k+1) - x(k)|| < error admisible o se alcanza el máximo de iteraciones.

Ventaja: Más eficiente que Jacobi al usar valores actualizados inmediatamente.
