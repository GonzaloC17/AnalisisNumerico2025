Información del Método

¿Qué es la Regresión Polinomial?

La regresión polinomial es una extensión de la regresión lineal que permite ajustar curvas polinomiales de grado n a un conjunto de puntos de datos. Utiliza el método de mínimos cuadrados para encontrar los coeficientes del polinomio que mejor se ajusta a los datos.

Ecuación general:

y = a₀ + a₁x + a₂x² + a₃x³ + ... + aₙxⁿ

Tipos de Polinomios

Grado 1: y = ax + b
Grado 2: y = ax² + bx + c
Grado 3: y = ax³ + bx² + cx + d
Grado 4: y = ax⁴ + bx³ + cx² + dx + e

Consideraciones:

  • • Mayor grado = mejor ajuste pero mayor complejidad
  • • Evitar overfitting (sobreajuste)
  • • El grado debe ser < número de puntos
  • • Usar R² para evaluar la calidad del ajuste
