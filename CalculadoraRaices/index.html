Métodos Cerrados

Bisección • Regla Falsa

Unidad 1

Requieren intervalo [xi, xd] donde la función cambie de signo. Garantizan convergencia.

Complejidad: O(log n)
Tipo: Directo
Convergencia: Garantizada

Cuándo usar:

  • • Función continua en [a,b]
  • • f(a) × f(b) < 0
  • • Se conoce el intervalo

Métodos Abiertos

Newton-Raphson • Secante

Unidad 1

Requieren aproximaciones iniciales. Convergencia rápida pero no garantizada.

Complejidad: O(n)
Tipo: Iterativo
Convergencia: Condicional

Cuándo usar:

  • • Función derivable
  • • Buena aproximación inicial
  • • Convergencia rápida deseada
Usar Métodos

Gauss-Jordan

Eliminación Directa

Unidad 2

Transforma la matriz en identidad. Solución exacta en pasos finitos.

Complejidad: O(n³)
Tipo: Directo
Precisión: Exacta

Cuándo usar:

  • • Sistemas pequeños (n ≤ 10)
  • • Matriz no singular
  • • Solución exacta requerida
Usar Método

Gauss-Seidel

Método Iterativo

Unidad 2

Método iterativo con control de error. Ideal para sistemas grandes.

Complejidad: O(n²)
Tipo: Iterativo
Convergencia: Si dominante

Cuándo usar:

  • • Sistemas grandes (n > 10)
  • • Matriz diagonalmente dominante
  • • Control de precisión deseado

Información del Proyecto

Objetivo

Desarrollar una herramienta educativa que permita encontrar raíces de ecuaciones f(x)=0 utilizando métodos numéricos tanto cerrados como abiertos, con visualización gráfica y resultados detallados.

Características

  • • Interfaz moderna y responsive
  • • Visualización gráfica con GeoGebra
  • • Modo oscuro/claro
  • • Validación de entrada robusta
  • • Resultados detallados paso a paso
